# 사진 청소기 (photo-clean-tool)

스레드·당근 등에 사진을 올리기 전에 **위치(GPS)·기기 정보(EXIF)를 완전히 지우고**, 얼굴·계좌번호·번호판 같은 부분을 **손가락으로 문질러 모자이크/블러/검정으로 가리는** 웹앱입니다.

## 핵심 원칙: 100% 브라우저 로컬 처리

- 고른 사진은 **어떤 서버로도 업로드되지 않습니다.** 파일은 브라우저 메모리에서만 읽히고, 저장 파일은 기기에서 직접 만들어집니다.
- 서버·DB·계정·로그인이 없습니다. 정적 HTML 한 장짜리 앱입니다.

## 기능

| 단계 | 내용 |
| --- | --- |
| 1. 미리보기 | 업로드한 사진의 EXIF를 파싱해 **GPS 좌표·고도·기기 제조사/모델·렌즈·촬영일시·소프트웨어·XMP/IPTC** 를 화면에 표시. 없으면 "위치·기기 정보 없음" 표시 |
| 2. 가리기 | `모자이크` / `블러` / `검정` 3가지, 브러시 3단(작게·보통·크게), **되돌리기·다시·전체 초기화**, 누르고 있으면 **원본 비교** |
| 3. 저장 | PNG / JPEG(고화질 0.95) 선택, **저장 파일을 다시 파싱해 EXIF·GPS·XMP가 0건인지 화면에서 검사**, `navigator.share` 지원 시 **공유 시트로 바로 공유** |

## 동작 방식

- EXIF 파서: JPEG APP1(`Exif\0\0`) TIFF IFD0/ExifIFD/GPS IFD 및 XMP, APP13(IPTC), COM 세그먼트를 직접 파싱합니다. 라이브러리 의존성 없음.
- 메타데이터 제거: `<canvas>`에 다시 그려 `toBlob()`으로 인코딩합니다. 캔버스 출력에는 EXIF/XMP/IPTC가 포함되지 않으므로, 결과물에는 JFIF/ICC(색상) 헤더만 남고 **위치·기기 정보는 0바이트**입니다.
- 가리기: 마스크 캔버스(모자이크·블러·검정)에 브러시 알파를 칠하고, 원본에서 만든 모자이크(블록)/블러 레이어를 마스크로 합성합니다. 되돌리기는 스트로크 재생 방식이라 메모리를 거의 쓰지 않습니다.
- 편집 해상도는 긴 변 기준 최대 2400px로 자동 축소합니다(모바일 메모리 보호).

## 배포

정적 파일이므로 `index.html` 하나를 아무 정적 호스팅에 올리면 됩니다. 이 저장소는 Vercel(`kimyelin` 팀)에 배포되어 있습니다.

## 사용 팁

- 저장한 파일은 **다운로드 폴더**에 들어갑니다. 사진첩으로 옮긴 뒤 올리면 됩니다.
- 원본 파일은 그대로 남습니다. 앱은 항상 **새 파일**을 만듭니다.
